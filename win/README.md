# 电视直播 · Windows 桌面版

一个独立的桌面程序：双击打开自己的窗口，不经过浏览器，没有地址栏。频道数据与 Android 电视版共用同一份内置源。

## 怎么用

**方式一：单文件 exe（推荐，不需要 Python）**

双击 `电视直播.exe`，弹出程序窗口即可看台。

**方式二：文件夹版（需要 Python 3.10+）**

双击 `启动.bat`，同样是弹出程序窗口。

首次运行若提示"未知发布者"，点「更多信息」→「仍要运行」（exe 未做代码签名）。

操作：点频道播放，`Esc` 关闭播放层，`↑` `↓` 切台，右上角「订阅源」换源。关闭窗口即退出，后台服务随窗口一起结束。

## 换自己的源

右上角「订阅源」→ 填 `http://` 或 `https://` 开头的 m3u / txt 地址 → 保存并切换。
地址需带主机名（如 `http://192.168.1.5:8080/tv.m3u`）。
点「恢复默认源」随时回到内置频道。

配置保存在程序目录的 `config.json`，换源后的频道缓存为 `cache.m3u`。

## 界面为什么是网页做的

窗口外壳是原生的（Windows WebView2 内嵌），里面的界面用 HTML 绘制。这样做的好处是复用 Android 版那套现成的 HLS 播放能力（hls.js），不必为桌面另写一套播放器。

窗口内部仍在 `127.0.0.1` 上起一个只服务本机的小服务，负责：

- 解析内置 m3u 源
- 代理直播流并把 m3u8 里的分片地址改写成同源地址（浏览器内核的跨域限制要求这么做）
- 给窗口提供频道列表页面

服务只绑定 `127.0.0.1` 并校验 Host 头，局域网其他设备无法访问；窗口关闭后服务立即停止。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击 exe 闪一下就没 | 系统缺 WebView2 运行时 | 安装 Microsoft Edge WebView2 Runtime（Win11 自带） |
| 双击 bat 闪退 | 没装 Python | 装 Python 3.10+，勾选 Add to PATH；或改用 exe |
| 提示端口被占用 | 8899 被占用 | 程序会自动往后找 20 个端口；也可 `--port 9000` |
| 一直转圈，之后提示「连接超时」 | 该源太慢（实测有单分片 5 MB 要 52 秒的台） | 换台；或在提示框里点「重试」 |
| 提示「H.265（HEVC）编码，内核解不了」 | 该台是 H.265 编码，hls.js 只支持 H.264 | 换台，这类台在网页内核里无解 |
| 提示「播放列表打不开」 | 源已失效或拒绝访问 | 换台；第三方源失效程序无法修复 |
| 画面卡顿 | 源服务器带宽不足 | 源本身问题，与播放器无关 |
| RTMP / RTSP 台播不了 | 浏览器内核不支持这两种协议 | 页面会提示「不支持的协议」 |

## 源质量说明（重要）

内置的 440 个频道来自第三方公开源，**能播的比例取决于源当天状态，不是程序能决定的**。实测一轮央视 + 卫视的结果：

| 状态 | 频道 |
|---|---|
| 流畅 | CCTV13、浙江卫视、东方卫视、河南卫视、内蒙古卫视 |
| 很慢（首分片 > 5 秒） | 黑龙江卫视、江西卫视 |
| 打不开 | CCTV5、CCTV8、CCTV12、CCTV15、CCTV16、深圳卫视、安徽卫视、辽宁卫视、吉林卫视 |
| H.265，内核不支持 | 湖南卫视 |

也就是说：**点十来个台里通常有几个能看，剩下的是源本身的问题**。程序现在会明确告诉你是"太慢"还是"编码不支持"，不再无限转圈。

想稳定看，建议换自己的源：右上角「订阅源」填你有把握的 m3u/txt 地址。

## 目录说明

```
win/
├─ desktop.py       桌面入口（原生窗口 + 服务线程）
├─ app.py           后台逻辑（选端口、数据目录、内置源定位），也支持纯浏览器模式
├─ server.py        HTTP 路由与静态文件
├─ channels.py      m3u / txt 解析与分组
├─ sources.py       订阅源下载、校验、持久化
├─ proxy.py         HLS 代理与 m3u8 地址重写
├─ static/          窗口内界面、播放层、hls.js
├─ tests/           pytest 用例
├─ build.py         打包成单文件窗口版 exe
└─ 启动.bat         源码方式启动窗口
```

## 开发

```bash
python -m pytest tests/ -v          # 跑测试
python desktop.py                   # 起窗口（开发用）
python app.py --no-browser          # 只起服务，用浏览器调试
python build.py                     # 打包 dist/电视直播.exe
```
